    Mini Banking System

    A console banking program in C. You can create accounts, deposit, withdraw, check a balance and delete accounts, and everything is saved in a file.

    • C
    • File handling
    • Menu-driven

    View code on GitHub

    • How it works: Account data is written to a binary file (accounts.dat), so it is still there the next time you run the program.
    • Safety checks: It refuses negative deposits and withdrawals, and checks the balance before a withdrawal.
    • Limits I know about: It supports 5 accounts, and names can’t have spaces yet.
    • Next steps: Dynamic memory for unlimited accounts, transaction history, and splitting the code into several files.

    C Password Manager

    A command-line password manager in C. It asks for a master password, then lets you add, view and delete saved logins.

    • C
    • XOR encryption
    • Binary files

    View code on GitHub

    • How it works: The master password and the saved logins are stored in binary files, encrypted with a simple XOR method. Typed passwords show as stars.
    • Honest note: XOR is good for learning but not strong security, so I don’t use it for real passwords.
    • Next steps: Search by site name, a password generator, and stronger encryption such as AES.
